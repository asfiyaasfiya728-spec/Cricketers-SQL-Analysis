# 🏏 Cricketers SQL Analysis Project

## 📌 Project Overview
This project demonstrates SQL-based data analysis on a cricketers dataset. The analysis includes salary calculations, team-wise performance insights, sorting, filtering, and grouping operations using SQL queries.
